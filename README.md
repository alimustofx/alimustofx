## About

I keep school technology running end to end — student data systems, internal portals, networking, and every server underneath. That usually means owning the whole stack myself: I write the Laravel applications teachers open every morning, and I run the Proxmox cluster and Linux boxes they live on.

I got here self-taught, and I'm currently studying Communication Science alongside the engineering work, because the systems I build only matter if the people using them actually understand them.
